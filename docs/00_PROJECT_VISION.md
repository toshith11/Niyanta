# NIYANTA

## Intelligent Personal Operating System

### Vision

Niyanta is an experimental operating system project
exploring the integration of operating-system principles,
personal intelligence, system awareness and controlled
autonomous actions.

## Commander

Commander is the intelligent control layer of Niyanta.

It is intended to understand the owner's instructions,
observe system state, reason about actions and interact
with the operating system within defined security boundaries.

## Long-Term Goal

Create a portable intelligent operating environment that
can adapt to different hardware platforms.

## Initial Hardware

An old Android smartphone will be used as an experimental
hardware platform in later stages.

## Initial Development

Development will begin using an emulator so that the
operating system can be debugged safely.

## Core Principle

Learn first.
Design second.
Implement third.
Measure fourth.
Improve continuously.
